# Dishdrop by SocialDrop Studio

Landing site for Dishdrop, an app that turns recipe links from TikTok, Instagram, YouTube, Pinterest, Facebook and food blogs into clean, cookable recipe cards.

Static site with no build step. Open `index.html` in a browser, or serve the folder:

```sh
npx serve .
```

- `index.html` – page content
- `styles.css` – design tokens (colours on `:root`) and layout
- `app.js` – brand name (`BRAND`), the hero import demo and the mobile download banner
- `assets/logo.svg` – logo
